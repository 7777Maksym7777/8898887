ЛАБОРАТОРНА РОБОТА №2 — Java Threads

Файли:
- Звіт_Лабораторна_робота_2.docx — готовий звіт (поля ПІБ/групи/викладача залишені для заповнення).
- Lab2Threads.java — вихідний код.
- run_output.txt — повний результат фактичного запуску.
- console_result.png — зображення консольного результату.

Запуск:
1. Встановити JDK (Java 17 або новіша).
2. Відкрити термінал у папці з Lab2Threads.java.
3. Виконати: javac Lab2Threads.java
4. Виконати: java Lab2Threads

Програму перевірено компіляцією та запуском на OpenJDK 21.
